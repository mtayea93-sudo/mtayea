# Mohamed Tayea — الموقع الشخصي

الموقع الشخصي الرسمي لـ **محمد طايع** — مطوّر واجهات ومصمم مواقع وتطبيقات ويب.

The official personal website of **Mohamed Tayea** — front-end developer & web designer.

## المعاينة | Preview

موقع صفحة واحدة بتصميم سينمائي داكن، علامة مائية خفيفة `m.tayea`، سكرول ناعم، وأنيميشن ظهور متدرج.

A single-page portfolio with a cinematic dark design, a subtle `m.tayea` watermark, smooth scrolling, and scroll-triggered reveal animations.

## التقنيات | Tech Stack

- HTML5 + CSS3 (متغيرات، Flex/Grid، `clamp()` للخطوط المتجاوبة)
- Vanilla JavaScript
- [GSAP](https://gsap.com/) + ScrollTrigger — animations
- [Lenis](https://lenis.darkroom.engineering/) — smooth scroll
- خطوط Google Fonts: Tajawal (عربي) + Hanken Grotesk (لاتيني)

## التشغيل | Run Locally

```bash
# أي سيرفر ملفات ثابتة يكفي — مثلاً:
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو ارفع المجلد على أي استضافة ثابتة: GitHub Pages / Vercel / Netlify.

Or deploy the folder as-is to any static host: GitHub Pages / Vercel / Netlify.

## الهيكل | Structure

```
├── index.html      # الصفحة الكاملة (HTML + CSS + JS)
└── assets/
    ├── work1.png   # رندر مشروع — داشبورد
    ├── work2.png   # رندر مشروع — بطاقات زجاجية
    └── work3.png   # رندر مشروع — تطبيق موبايل
```

## النشر على GitHub Pages | Deploy to GitHub Pages

1. ارفع الريبو على GitHub
2. من **Settings → Pages** اختار المصدر: `main` / `/ (root)`
3. الموقع هيشتغل على: `https://<اسم-المستخدم>.github.io/<اسم-الريبو>/`
